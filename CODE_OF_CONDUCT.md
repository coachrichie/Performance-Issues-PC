# Code of Conduct

## Our Commitment

We want this project to be a respectful, practical, and helpful place for everyone working on Windows diagnostics and troubleshooting.

## Expected Behavior

- Be respectful and constructive
- Focus on reproducible technical facts
- Document risks and side effects clearly
- Protect sensitive system and user data
- Assume good intent and ask for clarification before escalating conflict

## Unacceptable Behavior

- Harassment, discrimination, or intimidation
- Sharing credentials, private data, or customer data without permission
- Recommending unsafe cleanup, tuning, or destructive actions without clear warnings
- Misrepresenting test results, logs, or diagnostic findings

## Enforcement

Project maintainers may remove content, reject contributions, or restrict participation when behavior violates this code of conduct.

## Reporting

Report serious issues privately to the project maintainer through the repository contact channel that is configured for the project.
